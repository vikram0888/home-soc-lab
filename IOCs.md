# Indicators of Compromise (IOCs)

Patterns, commands, and identifiers generated by this lab's simulated attack chain. These are lab-generated indicators for demonstration purposes, not indicators from a real-world incident.

## Detection rule (regex pattern)

The core pattern used to flag suspicious PowerShell activity:

```
(?i)(IEX|Invoke-Expression|-enc|-EncodedCommand|-nop|-NoProfile|DownloadString|AtomicRedTeam|SOAPHound|mimikatz|sekurlsa)
```

Matched against Sysmon Event ID 1 (`CommandLine` field) where `Image` is `powershell.exe`.

## Suspicious command-line patterns observed

| Pattern / keyword | What it indicates |
|---|---|
| `IEX (New-Object Net.WebClient).DownloadString(...)` | Fileless download-and-execute cradle |
| `$comObj = New-Object -ComObject MsXml2.ServerXmlHttp` | Download cradle via COM object (evasion technique, avoids common WebClient/IEX signatures) |
| `-EncodedCommand`, `-E`, `-EncodedArguments` followed by a long base64 string | Obfuscated/encoded command execution |
| `Import-Module ...Invoke-Mimikatz.ps1` | Credential-dumping tool load |
| `invoke-mimikatz -dumpcr` / `sekurlsa::logonpasswords` | Credential dumping execution |
| `Import-Module ...SharpHound.ps1` | Active Directory reconnaissance tooling |
| `SOAPHound.exe --user ... --password ... --dc <ip> --buildcache` | AD enumeration via SOAPHound |
| `Invoke-AppPathBypass` | Application allowlist / UAC bypass technique |
| Function definitions for `Invoke-Shellcode`, `Invoke-TokenManipulation`, `Get-Keystrokes`, `Out-Minidump`, etc. | Known offensive PowerShell module (PowerSploit-style) tool names |
